# `svadba`

Свадебный сайт на `Vue 3 + Vite` с автодеплоем в `GitHub Pages`.

## Локальный запуск

```bash
npm install
npm run dev
```

Локально сайт обычно доступен по адресу:

```text
http://localhost:5173/
```

## Сборка

```bash
npm run build
```

Готовый production-бандл попадает в папку `dist/`.
